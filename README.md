# LRVC Live Captions

Live captions of the Sunday message at Lake Region Vineyard, Bridgton, Maine.

A single static page (`index.html`). Open it in Chrome, Edge, or Safari and press Start.

- **Browser engine:** free, uses the browser's built-in speech service and the default microphone.
- **Deepgram engine:** paste a Deepgram API key in Settings. The key is stored only in that browser's local storage. It is never part of this repository.

Deployed on Vercel. Every push to `main` redeploys.
